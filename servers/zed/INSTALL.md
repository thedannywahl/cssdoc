# cssdoc for Zed

Extract this archive to a permanent directory. In Zed, open **zed: install dev extension** and
select that directory. This overrides the registry version if one is installed. The extension
installs the matching `@cssdoc/language-server` package when needed; this requires network access
and Node.js 26 or newer.

The archive contains a prebuilt WebAssembly extension and no Rust source. For source and settings,
see the [extension README](https://github.com/thedannywahl/cssdoc/tree/main/servers/zed).
