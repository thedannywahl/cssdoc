# Reference

Look up syntax and settings, or explore how cssdoc handles more involved cases.

## Authoring

- [Doc-comment tags](/guide/doc-comment-tags) covers tag syntax, comment formatting, and annotations.
- [Selectors and structure](/guide/selectors-and-structure) covers selector matching, record
  relationships, and worked examples of alternative layouts and optional wrappers.

## Project behavior

- [Configuration](/guide/config-reference) indexes every top-level field and explains inheritance,
  providers, overrides, and render settings.
- [Lint rules and diagnostics](/guide/lint-reference) explains class usage checks, registered-property
  diagnostics, and suppression directives.
- [Language server](/guide/language-server-reference) covers LSP features, settings, discovery, and
  refresh behavior.
- [Embedded CSS support](/guide/embedded-css-support) lists supported host files and dialects and
  explains how tools extract and check their styles.

## Specification

- [Formal grammar](/guide/grammar) defines the syntax of a cssdoc comment.
- [Regex patterns](/guide/patterns) connects the patterns used by cssdoc to grammar productions.

For installation and programmatic APIs, see [Packages](/guide/packages) and the [API](/api/).
